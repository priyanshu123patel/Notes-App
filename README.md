# Notes-App
# Syntacxhub Workspace

This workspace contains a React + Vite notes application.

## Project Structure

- `Notes App/` - Main notes app built with React and Vite

## Getting Started

1. Open a terminal in the `Notes App` folder.
2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open the URL shown in terminal (usually `http://localhost:5173`).

## Build for Production

From inside `Notes App`:

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Notes App Features

- Create notes with title and content
- View and edit notes
- Archive and unarchive notes
- Trash with permanent delete option
- Search notes by title
- Theme toggle (light/dark)
- Local storage persistence

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES modules)
